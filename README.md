# 🏢 Employee Management System (Spring Boot + React + MySQL)

A **simple Employee Management System (EMS)** built using **Spring Boot (Backend), React.js (Frontend), and MySQL (Database)** that allows users to **perform CRUD operations** (Create, Read, Update, Delete) on employee records.
---
## 🚀 Features
- 📌 **Add New Employees**
- 📄 **View Employee List**
- ✏ **Update Employee Details**
- ❌ **Delete Employees**
- 🗃 **Store Data in MySQL Database**
  
---

## 🛠 Tech Stack
- **Frontend:** React.js, Axios, Bootstrap , CSS , HTML  
- **Backend:** Spring Boot, Spring Data JPA, REST APIs  
- **Database:** MySQL  
- **Tools:** Postman, IntelliJ IDEA, VS Code
